WHO I AM

LEARNING CARS
ONE PROJECT AT A TIME.

I'm L@NC3R, a beginner automotive tuner and modder from Australia.

I created this site to document my journey as I learn more about automotive tuning, modifications, diagnostics and hands-on mechanical work.

I'm not a professional tuner. I'm learning by working on my own cars, researching how different systems work and taking on new projects as my knowledge grows.

My current main project is my 2009 Mitsubishi Lancer MIVEC, which I'm using to learn more about diagnostics, ECU tuning and vehicle modification.
